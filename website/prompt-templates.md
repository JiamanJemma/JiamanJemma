# AI 提示词模板合集（新手友好版）

> 整理：佳蔓Jemma | jiamanjemma.com
> 适用于：ChatGPT / Claude / Gemini / 任何 AI 对话工具
> 用法：复制模板 → 替换【】里的内容 → 粘贴给 AI

---

## 一、写作 & 文案

### 帮我润色文章
```
请帮我润色以下文章，保持我的个人风格和语气不变，只优化表达流畅度和错别字：

【粘贴你的文章】
```

### 帮我起标题
```
我写了一篇关于【主题】的文章，目标读者是【受众】。
请给我 5 个标题选项，风格分别是：
1. 好奇型（让人想点进来）
2. 数字型（带具体数字）
3. 反认知型（挑战常识）
4. 共鸣型（情绪共鸣）
5. 实用型（直接说价值）
```

### 小红书文案
```
帮我写一条小红书文案：
主题：【主题】
风格：口语化、短句、分段、带 emoji
字数：300-500字
标题要求：20字以内，带 emoji
最后加 5-8 个相关标签
```

## 二、学习 & 理解

### 用大白话解释概念
```
请用最简单的语言解释【概念】，就像在跟一个完全不懂的朋友聊天。
不要用专业术语，多用比喻和生活中的例子。
```

### 帮我做学习笔记
```
请帮我总结以下内容的核心要点，用这个格式：
- 一句话总结
- 3-5 个关键要点（每个配一句解释）
- 我可以怎么用（1-2个行动建议）

【粘贴学习内容】
```

### 读书笔记
```
请帮我整理《【书名】》的核心内容：
1. 这本书在讲什么（一段话）
2. 最重要的 3-5 个观点
3. 每个观点配一个生活中的例子
4. 读完可以立刻做的 1 件事
```

## 三、头脑风暴

### 帮我想选题
```
我是一个【身份/领域】的创作者，受众是【目标人群】。
请帮我想 10 个内容选题，要求：
- 有搜索量（别人会主动搜的）
- 有差异化（不是人人都在讲的角度）
- 标注每个选题适合的内容形式（视频/图文/长文）
```

### 帮我想方案
```
我想要【目标】，但遇到了【困难/限制】。
请给我 3 个不同思路的方案，每个方案包括：
- 核心思路
- 具体步骤
- 优缺点
- 适合什么情况
```

## 四、翻译 & 改写

### 中英翻译（自然风格）
```
请翻译以下内容为【中文/英文】。
要求：自然流畅，像母语者写的，不要翻译腔。
如果有文化差异的表达，请本地化处理。

【粘贴内容】
```

### 改变语气风格
```
请把以下内容改写为【正式/轻松/专业/口语化/学术】风格，
保持核心意思不变：

【粘贴内容】
```

## 五、效率工具

### 会议/对话总结
```
请帮我总结以下会议记录/对话内容：
1. 核心结论（1-2句）
2. 待办事项（列出具体行动+负责人）
3. 未解决的问题

【粘贴内容】
```

### 帮我写邮件
```
帮我写一封【正式/半正式/轻松】的邮件：
收件人：【谁】
目的：【做什么】
关键信息：【要传达的内容】
语气：【专业友好/简洁直接/礼貌委婉】
```

### 对比分析
```
请帮我对比【A】和【B】，用表格展示：
- 核心功能
- 优缺点
- 价格
- 适合人群
最后给出你的推荐和理由。
```

## 六、进阶技巧

### 让 AI 扮演专家
```
你是一位有 10 年经验的【领域】专家。
我的情况是：【描述你的情况】
请用你的专业知识，给我【具体需要的帮助】。
如果需要更多信息，请先问我。
```

### 让 AI 反复优化
```
请帮我【任务】。完成后，请自己检查一遍，列出 3 个可以改进的地方，然后给出改进版。
```

### 让 AI 提问引导你
```
我想【目标】，但还没想清楚。
请不要直接给答案，先问我 5 个关键问题，帮我理清思路。
```

## 使用心得

1. **越具体越好** — "帮我写文案"不如"帮我写一条小红书文案，主题是XX，300字"
2. **给 AI 角色** — "你是一位XX专家"能让回答更专业
3. **不满意就追问** — 说"再简洁一点"、"换个角度"、"多给几个选项"
4. **提供示例** — "参考这个风格：【例子】"效果远好于纯描述
