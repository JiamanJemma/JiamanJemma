# 🔵 #06 效率尽头：我把 NotebookLM 搬进了终端命令行
## —— 不开网页、零提示词，属于“一人公司”的自动极客流


> **【公众号封面】**
![封面](images/06_cover_wide.png)

每次打开浏览器，我都觉得脑子里的某个齿轮卡了一下。

建个新标签页。
输入网址。
等进度条。
把几十个视频链接、网页文章拖拽进去。
然后开始对着输入框发愣，努力回忆复杂的 Prompt 公式。

对很多人来说，这是常规的知识管理流程。
但对我这种重度依赖输入输出的“一人公司”来说，**切网页这个动作本身，就是一种极大的损耗。**

它打断了心流。
打断了灵感迸发那一瞬间的直觉。

![浏览器之痛](images/06_01_browser_pain.png)

所以这几天我干了一件挺疯狂的事：
**我把整个 NotebookLM，直接塞进了黑框框的终端（Terminal）里。**

> 📺 **视频版：** [如何在终端调用 NotebookLM？（自动生成思维导图/信息图）](https://youtu.be/6F1NdwwEG2c?si=QpBdHb4XcnTz8-ZU)

其实刚开始弄的时候，只是因为嫌烦。

每次做视频复盘、或者拆解长文的时候，
我要把大量的资料塞给 AI，让它帮我拉个大纲。
后来我发现 GitHub 上有个开源库，叫 `notebooklm-py` 的 NotebookLM CLI（[github.com/teng-lin/notebooklm-py](https://github.com/teng-lin/notebooklm-py)）。
只需要几行代码安装好，世界就完全变了。

现在我不用打开任何网页了。

在屏幕边缘敲出终端黑框，
用最原始的命令行，直接把几十篇网页和 YouTube 字母链接一键批量导入。
接着，在黑框框里敲一句大白话：
——“帮我把这些资料里提到的所有 AI 工具分类，画个思维导图。”

不用写什么牛逼的 Prompt 咒语。
然后看着终端里，绿色的代码一行行滚过。

更可怕的是，我现在激活了 **Deep Research** 功能。
我只要用大白话丢个模糊的问题进去，
AI 会在后台默默联网搜索、比对、总结，最后补全我知识库里没有的盲区。

然后，几秒钟后。
一张逻辑严密的思维导图，或者极其漂亮的信息图，直接存到了我的本地文件夹里。
全程没有打开过一次浏览器。

![终端魔法](images/06_02_terminal_magic.png)

这就是技术赋能超级个体的终极模样：
**去界面化。去摩擦力。**

少一步操作，就能把挤出来的心智能量，全部留给真正的思考。

![禅意工作流](images/06_03_zen_flow.png)

如果你也是一个靠知识管理活着的创作者。
如果你也厌倦了每天繁杂的工具面板和弹窗。
强烈建议你看看今天视频里的这套工作流。

终端上的光标还在闪烁。
它在等我的下一个想法。
