# #05 从黑框到精装房，我搬家了

*$200 → $40，体验还更好了。*

用了一个月 Claude Max，做了两个 App、一个网站、一整套创作系统。
全是在终端里完成的。

## Claude Code 很强

一个想法扔进去，它能帮我从头搭起来。
改代码、跑测试、部署上线，一条龙。
token 无限用，不用算。

但有几件事一直别扭。

终端里看文件要翻找。
看图片要另外打开。
想用点配图，只能放几张干巴巴的截图，毫无审美。
想操作网页，体验也卡顿。

最痛的是这种碎片化的消耗。
为了调个配置、看一眼刚刚生成的图，我能在黑窗格和各个窗口间切来切去一下午。
而且终端的对话保存不了。
每次关掉，上下文就全变成了记忆黑洞，早期存的文件也全乱了。

![[05_01_终端痛点.png]]

那一个月是我最疯狂的时候。
其实靠敲命令，什么功能都能搓出来。
但，真的太绕了。

而且基础流程搭完后，我经常让 Claude 去问 Gemini AIGC 的事。
比如征求意见、帮出提示词。
但这需要我当中间人：Claude 生词、发给 Gemini、等反馈、再传回。
一来一回，肯定有信息损耗，也费时间。

那时就开始想：有没有一种工具，能把这几步合在一起？

刚好那天参加 mini hackathon，Ray 临时上来分享，说自己在用 Antigravity。我们组长也在用。
当时没有马上行动，但心里埋下了一颗种子。

## 遇到 Antigravity

也很巧。之前随手挂了个拼车帖，一直没人接。结果在 Claude Max 到期前一天，突然拼好了。

当时还有点犹豫，觉得舍不得 Claude。但想了想，爆发期过了，之后还是以创作为主，不需要那么重的工具了。

于是就让 Claude 帮我整理搬家文件——把对话里攒下来的配置、脚本、笔记，全部归档到本地。

刚整理好，我们就拼好了 Google 的 Ultra 家庭组。
Antigravity 就是这时候进来的。

第一感觉：很像 VS Code 翻版。

文件树在左边，代码在中，聊天在右，底部开终端。

直接出图的体验特别好。
用 Opus 4.6 出了我喜欢的泥塑风，需要 3D 渲染。
这在纯 Claude 终端里做不到。
要是强行通过 NotebookLM 去生图，控制力弱，不够自然，还得后期去水印。
这儿自带图片原生生成，干净利落。

因为是 Google 全家桶，操作 Chrome 也异常顺滑。
能清晰地看到鼠标在屏幕上移动、点击。
说"帮我打开 Google Calendar"，它就直接打开，还能顺手安排提醒。
就像对面坐了一个真的助理。
不用记命令，不用自己动手，这让人很惊喜。

最让我意外的，是它好像自带了一套审美。

如果说终端是毛坯房，那 Antigravity 就是豪华精装房。该配的都配齐了——图片生成、浏览器操作、文件管理、多模型切换。没带的，也能通过 MCP 接入"软装"，按自己的喜好添置"家具"。

![[05_02_界面惊喜.png]]

同样的需求，同样用 Claude 模型，做出来的东西天然更好看。
做 Remotion 动画的时候尤其明显。
终端里做 Remotion，得装 skills 让 Claude 去学习。
这里不用。它自己就知道怎么做好看。

这段时间我还让它帮我升级了 IP 形象、做了封面素材、出了各种配图。
说实话，反复出图、出视频很费 token。但 Ultra 的模型使用量非常充裕，完全不用担心。

工具不只是能力的差别。
是思维方式的差别。
终端是"我来指挥"，这个界面是"我们一起做"。

## 最现实的原因

既然体验这么像豪华精装房，是不是代价很高？
恰恰相反。

Claude Max，$200 一个月。
Antigravity 家庭组，一人大概 $40。

$200 vs $40。

![[05_03_性价比.png]]

不是 Claude 不值。
是那种强度不可能每个月都维持。

那个月是爆发期。高峰。
但高峰不是常态。

日常创作，$40 够了。
写文案、做动画、管文件、搞数据、生成配图。
该做的事一样做，还多了图片生成和浏览器操作。

最贵的工具不一定最好。
最适合日常节奏的才是。

作为创作者，不是程序员。
我需要的不是最强的工具。
是最趁手的那个。
