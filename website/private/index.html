Private Studio

只给你自己的入口

这是挂在主站下面的一条私密链路，适合放你自己的工作台入口、草稿导航、 内部工具链接，或者任何你不想公开给所有访问者看的页面。

Local Only

本地工作台

像 Jemma 工作台 这种本地目录，不能从公开网页直接打开。 最稳的方式是把最短命令留在这里，你在自己电脑终端里执行。

看工作台 cd ~/Desktop/Jemma工作台 && ./jemma watch
看下一步任务 cd ~/Desktop/Jemma工作台 && ./jemma next
看任务详情 cd ~/Desktop/Jemma工作台 && ./jemma show creator-playbooks
部署后记得设置环境变量： PRIVATE_USER 和 PRIVATE_PASS
