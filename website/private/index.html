Quick Notes

固定检查项

Publish Checklist

发内容前看一眼

  • 标题和封面是不是同一个叙事，不要各说各话。
  • 公开页、简介区、置顶评论有没有放对入口。
  • 视频、长文、站内资源三边有没有互相导流。
  • 发完后从手机再看一遍公开呈现，不只看后台。
Site Checks

改站后看一眼

  • 主页首屏、作品区、资源区有没有断层。
  • `/private/` 认证有没有还活着，环境变量别丢。
  • 改完样式后，手机视图和公开页按钮再点一遍。
  • 最后回 GitHub 看 diff，别把实验改动混进正式页面。

Reminder

今天别忘了

先决定今天这次上线是为了什么，再去改页面。不要一边想定位，一边顺手改十个地方。

私密页的价值不是“藏很多链接”，而是让你每天最短路径回到真正重要的事。

Local Only

本地工作台

像 Jemma 工作台 这种本地目录，不能从公开网页直接打开。 最稳的方式是把最短命令留在这里，你在自己电脑终端里执行。

部署后记得设置环境变量： PRIVATE_USER 和 PRIVATE_PASS
